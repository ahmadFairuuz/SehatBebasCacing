> **"Bersama Wujudkan Generasi Sehat Tanpa Cacingan"**

**SehatBebasCacing** adalah inisiatif web edukatif dan interaktif yang dirancang untuk meningkatkan kesadaran masyarakat akan pentingnya kebersihan serta pencegahan penyakit cacingan (*helminthiasis*). Platform ini menggabungkan edukasi publik, fitur pemindaian mandiri gejala kesehatan, dan pengolahan data pengguna secara terintegrasi.

---

## 📊 Key Focus & Awareness Metrics

- **1,5 Miliar+** — Orang di dunia terinfeksi cacingan (Global Impact Awareness).
- **80%** — Kasus terjadi pada anak usia sekolah.
- **100%** — Dapat dicegah melalui edukasi pola hidup bersih dan intervensi dini.

---

## 🌟 Fitur Utama

- **Interaktif Health Screening:** Form penilaian gejala dan pengumpulan biodata pengguna secara *real-time* berbasis PHP serverless API.
- **Pusat Edukasi & Artikel Medis:** Folder modul edukasi kesehatan terstruktur (`artikel1.html` - `artikel5.html`) seputar perilaku hidup bersih dan sehat (PHBS).
- **Portal Layanan Kesehatan Terpadu:** Halaman navigasi komprehensif mencakup *Departments*, *Doctors*, *Appointments*, *Services*, dan *FAQ*.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, CSS3, JavaScript (Responsive Web Design)
- **Backend:** PHP (Vercel Serverless Functions via `/api`)
- **Deployment:** Vercel (`vercel.json`)
